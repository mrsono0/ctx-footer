# 01. 기능 정의

## 1. 배경과 사용자 결정 (원문)
- 「두번째 줄에 출력 하거나 "── kickoff-prompt.md 팀 구성 및 환경 설정 ─" 이쪽에 출력 해주는 스킬 플러그인은 없는 것인가?」
- 「dashband 의 설정 방법을 더 구체적으로 알아 본다. 밴드의 줄수? 크기?를 조정하거나 비활성 할 수있는지 등.」 → dashband는 설정이 없고 입력창 위 밴드(2~4줄)를 항상 그린다.
- 「B안으로 가는데 dashband 소스 코드를 최대한 차용해서(필요한 부분만) 안전하면서 미니멀하게 구현을 합니다.」
- 앞선 결정: 상시 표시·미니멀. 공식 `statusLine`은 "renders in its own row above the built-in footer badges"라 줄이 하나 늘어서 대안을 찾게 됐다.

## 2. 목적 (한 줄)
줄을 하나도 늘리지 않고, 바닥줄 오른쪽 모드 라벨 자리에 컨텍스트 창 사용량을 항상 보여 준다.

## 3. 기능 요구 (F)
| ID | 요구 | 비고 |
|---|---|---|
| F1 | 바닥줄 `SessionMode` 자리에 폭에 따른 라벨을 덧붙인다 — 넓은 화면 `ctx <퍼센트>% · <토큰k>/<창k>`, 좁은 화면(기준 폭 미만·viewport 없음) `ctx <퍼센트>%` | 형식 확정(2026-10-11, 사용자 원문 「작은 화면은 ctx 53% 유지, 넓은 화면으로 변경되면 원래대로 복원」). 기준 폭 출발값 100(M5, P5 실측). 엔진의 기존 모드 라벨은 그대로 둔다 |
| F2 | 값은 엔진의 `$.session.usage().context`(tokens, window, percent)만 쓴다 | statusLine의 `total_input_tokens`·`context_window_size`·`used_percentage`와 같은 값 |
| F3 | 값이 바뀌면(턴 종료, 압축 후 첫 응답 등) 다시 그린다 | 엔진이 미는 `session.measure` 이벤트 사용(폴링 없음) |
| F4 | 첫 응답 전·압축 직후처럼 값이 없을 때는 라벨을 붙이지 않거나 `ctx …`로 둔다 | 설계에서 하나로 정한다(D-3) |
| F5 | 터미널과 데스크톱 앱 표면에서 동작한다(`SessionMode`가 그 둘에서만 raise됨) | 다른 표면은 건드리지 않는다 |
| F6 | 기존 커스텀 `statusLine`을 지우면 하단이 한 줄이 된다 | 설치 단계에서 사용자 승인 후 정리 |
| F7 | 배포: GitHub 저장소 주소(`mrsono0/ctx-footer`)로 설치 가능하게 한다 | 공식 마켓플레이스 디렉터리 등록은 안 함(사용자 결정 「깃헙 주소로만 설치」) |

## 4. 비기능 요구 (N)
| ID | 요구 |
|---|---|
| N1 안전 | `$.process`·`$.fs`·네트워크·`$.session.send/append/authorize`를 쓰지 않는다. 외부 전송 0 |
| N2 미니멀 | 모듈 1개, 표시 1개. 밴드·토스트·패널·명령·설정 없음(필요가 확인되면 추가) |
| N3 가벼움 | 타이머 없음. 그리기 경로에서 무거운 계산 없음 |
| N4 실패 무해 | 훅이 실패해도 엔진 기본 바닥줄이 그대로 나온다(`next(e)` 경로 보존) |
| N5 출처 | dashband에서 차용한 코드는 MIT 저작권 고지를 유지한다 |
| N6 호환 | 현 환경 Claude Code 2.1.296. 최소 요구 버전은 분석에서 확인한 값으로 README에 적는다 |

## 5. 비목표
- 프롬프트 캐시 카운트다운, 사용 한도(5h/주간), 비용 표시(dashband의 나머지 기능)
- 입력창 위 밴드(AbovePrompt), 세션 이름(구분선 제목) 변경 — 공식 수단 없음 확인
- 공식 마켓플레이스 디렉터리 등록(GitHub 주소 설치 배포는 F7)

## 6. 인수 기준 (A)
- A1 실제 화면: 바닥줄 한 줄 오른쪽에 폭에 따른 형식(`ctx N%` 또는 `ctx N% · Xk/Yk`)이 보이고, 폭을 바꾸면 형식이 전환된다(별도 상태줄이 없을 때 하단은 한 줄)
- A2 턴이 끝나면 값이 바뀐다(두 턴 이상 관찰)
- A3 값이 없을 때 F4 규칙대로 보인다
- A4 `claude plugin validate`, 타입 검사, `claude plugin test` 통과
- A5 코드에 N1 금지 API 호출이 없다(검색으로 확인)
- A6 사용자 원문 승인 후 전역 설치·statusLine 정리
